# M10 내보내기 파일 영속성 검증

`document:export`는 먼저 목적지와 원본 경로의 동일 파일 여부를 확인합니다. SVG, PNG, JPEG, PDF, 평면 PSD는 목적지와 같은 폴더에 고유한 임시 파일로 완성한 다음 실제 파일 종류와 바이트 크기를 확인하고 목적지로 이동합니다. 생성 도중 오류가 나면 기존 목적지 파일을 건드리지 않습니다. 성공 응답에는 최종 저장 경로와 디스크에서 다시 읽은 실제 바이트 크기가 포함됩니다.

AI 내보내기는 AI 저장 대화상자를 열기 전에 Windows PowerShell에서 `Illustrator.Application` COM 자동화 객체를 생성해 사용 가능 여부를 검사합니다. 미등록(COM `REGDB_E_CLASSNOTREG` 포함), 비 Windows 환경, 검사 시간 초과, 자동화 시작 실패에서는 오류 스택을 노출하지 않고 SVG 내보내기 또는 취소를 선택하도록 안내합니다. SVG를 선택하면 실제 `.svg` 파일을 기존 파일 보호 방식으로 저장하고 디스크에서 크기와 내용을 확인합니다. 이 성공은 UI에서 SVG로 표시되며 AI 저장으로 오인되지 않습니다. 취소하면 저장 대화상자를 열지 않고 파일도 만들지 않습니다.

COM 점검을 통과한 경우 Illustrator가 SVG를 열고 PDF 호환 네이티브 AI로 저장한 뒤 문서를 닫고 저장한 AI를 다시 열 수 있어야 성공합니다. 저장 파일 자체는 PDF 호환 서명, 끝 표시, 비어 있지 않은 길이로 검사하고 최종 저장본의 SHA-256을 방금 저장한 데이터와 비교합니다. `inspectAi`의 제한된 파싱 결과를 성공 판정에 사용하지 않습니다. 유효성이 확인된 임시 AI만 최종 경로에 반영됩니다. 이후 자동화가 실패하더라도 사용자에게 간결한 안내를 표시하고 임시 파일을 정리하며, 가짜 `.ai` 파일을 만들지 않습니다.

PowerShell 오류는 PowerShell 5.1의 시스템 코드 페이지나 표준 출력 스트림에 맡기지 않습니다. 자동화 스크립트는 오류를 UTF-8 파일로 기록하고 Electron 프로세스는 이를 UTF-8로 읽습니다. PowerShell stdout/stderr 스트림은 사용자에게 바이너리나 인코딩이 깨진 출력을 노출하지 않도록 무시합니다. COM 사전 점검 실패는 SVG 대안 선택지로 안내하고, 이후 자동화 실패·시간 초과·취소는 사용자용 요약 메시지로 전달합니다.

## Windows E2E

`apps/editor/scripts/m10-export-persistence-smoke.cjs`와 `m10-batch-user-flow-smoke.cjs`는 COM 미등록 상태를 재현해 SVG 대안 선택과 취소를 검사합니다. 취소 시 `.ai`와 `.svg` 모두 생성되지 않는지 확인한 뒤 SVG 대안이 실제 파일로 생성되고 벡터 내용 및 UI의 SVG 성공 문구가 일치하는지 확인합니다. 두 흐름 모두 가짜 AI 파일이 없는지 확인합니다. 네이티브 AI 저장·닫기·재열기 코드는 기존 경로를 유지합니다.

이 검증은 `.github/workflows/m4-packaging-validation.yml`의 Windows 패키징 작업에 연결되어 있습니다. CI의 Windows 이미지에 Illustrator가 없는 경우 미설치 분기가 실행됩니다. Illustrator 설치가 제공되는 환경에서만 네이티브 저장·재열기 분기가 실제 실행됩니다.
