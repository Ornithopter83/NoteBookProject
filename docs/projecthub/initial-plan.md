# Northstar 초기 설계 계획

## 프로젝트 개요

Northstar는 Windows 데스크톱에서 동작하는 레이어 기반 그래픽 편집기다. 저장소는 기준 커밋 `origin/main` (`1865a9eca154c222816d3de0386ae94d84dbc8a4`)을 바탕으로 새로 구축한다.

## 목표

사용자가 도형·텍스트·이미지·벡터 객체를 만들고 선택·변형하며 레이어를 관리할 수 있는 편집기를 제공한다. Undo/Redo와 자체 문서 형식 `.nbdoc`의 저장 및 재열기를 지원한다. PSD 및 PDF 호환 AI 문서는 검증된 지원 범위 안에서 읽고 편집하거나 변환한다.

데이터 손실 가능성을 작업 전에 알리고, 지원되지 않거나 결과를 신뢰할 수 없는 변환은 거부한다. 포맷을 단순히 바꾸어 저장하는 동작을 호환성으로 표현하지 않는다.

## 구성

- `apps/editor`: Electron·React·TypeScript·Vite 기반 Windows 데스크톱 앱. 캔버스, 레이어·속성 패널, 문서 모델과 안전한 preload IPC를 제공한다.
- `packages/psd-bridge`: `ag-psd` 기반 독립 PSD 모듈. 지원되는 계층·래스터·속성을 읽고 편집해 PSD로 저장한다.
- `packages/ai-bridge`: PDF 호환 AI 판별 모듈. 검증 가능한 벡터 경로와 텍스트만 제한적으로 분석하고, 안전한 PDF 출력 및 재파싱을 지원한다.
- `docs/projecthub/initial-plan.md`: 계획, 마일스톤, 완료 조건 및 포맷 호환성 제한을 기록하는 문서.

## 마일스톤

### M1 — 기본 편집기와 독립 포맷 모듈

기본 GUI와 객체·레이어 편집, Undo/Redo, `.nbdoc` 저장·재열기를 구현한다. PSD Bridge와 AI Bridge는 앱에서 분리된 모듈로 구성하고 각각 빌드 및 자동 테스트가 가능해야 한다. 편집기와 두 모듈의 빌드·테스트를 완료한다.

### M2 — PSD 및 PDF 호환 AI 통합

PSD를 편집기에서 열고 지원 범위의 레이어를 왕복시킨다. PDF 호환 AI의 가져오기 경로를 연결하고, 포맷별로 보존되지 않는 데이터와 변환 손실을 사용자에게 표시한다.

### M3 — 편집 기능과 안정성 확장

정밀 변형, 그룹, 텍스트·벡터 편집, 추가 레이어 속성을 제공하고 편집 안정성을 높인다. 네이티브 AI 저장은 검증된 백엔드가 있을 때만 구현 대상으로 삼는다.

### M4 — 호환성 및 배포 검증

실제 Adobe 애플리케이션에서 만든 샘플, 대용량 입력 및 오류 입력으로 호환성과 손실 처리를 검증한다. Windows 패키징과 실행을 확인한다.

## 완료 기준

최종 완료는 다음 항목을 모두 확인한 뒤 선언한다.

1. Windows 패키지가 실행되고 기본 편집기 GUI가 정상 동작한다.
2. 도형·텍스트·이미지·벡터 객체와 레이어를 생성·선택·변형·관리하고 Undo/Redo할 수 있다.
3. `.nbdoc` 문서를 저장한 뒤 다시 열었을 때 문서 내용과 상대 리소스가 보존된다.
4. 명시된 지원 범위의 PSD가 편집기 왕복에서 레이어 계층과 픽셀을 보존하며, 지원하지 않는 내용은 경고되거나 거부된다.
5. PDF 호환 AI 파일을 판별하고 지원 가능한 내용만 가져오며, 비호환·손상·미지원 구조를 안전하게 거부한다.
6. 변환 손실 경고, 오류 입력 처리, 대용량 입력 및 실제 Adobe 생성 샘플 검증을 완료한다.
7. 독립 빌드와 자동 테스트, Windows 패키징·실행 검사를 통과한다. 실행하지 못한 검증은 완료로 간주하지 않고 별도 기록한다.

## Adobe 포맷 호환성 및 제한

- PSD 호환성은 구현하고 실제 샘플로 검증한 기능에 한정한다. 모든 Photoshop 기능이나 모든 PSD를 보존한다고 보장하지 않는다. 지원하지 않는 레이어 유형·효과·메타데이터가 발견되면 손실을 알리거나 편집·저장을 거부한다.
- `.ai` 가져오기는 PDF 호환 부분에만 적용한다. 파일의 구조를 판별하고 검증 가능한 벡터 경로·텍스트만 분석한다. 미지원 구조나 손상된 파일은 추측하여 변환하지 않는다.
- PDF 호환 AI를 내보내거나 PDF로 출력할 수 있더라도 이를 네이티브 Illustrator `.ai` 저장으로 부르거나 표시하지 않는다. PDF 바이트를 `.ai` 확장자로 바꾸는 방식은 허용하지 않는다.
- Adobe 애플리케이션에서 생성된 샘플로 검증하지 않은 동작은 Adobe 호환성을 보장한다고 주장하지 않는다. 손실 가능성이 있는 변환에는 구체적인 경고를 제공한다.
